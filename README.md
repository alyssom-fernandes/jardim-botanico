# Mapa do Jardim Botânico do Rio de Janeiro

Mapa para usar no celular dentro do Jardim: ponto azul do GPS, direção para onde o celular aponta, os 63 pontos numerados das placas oficiais, banheiros, bebedouros e lanchonetes, e rota a pé pelos caminhos.

- Caminhos, lagos, rio e prédios: © colaboradores do OpenStreetMap (ODbL).
- Pontos numerados: placa oficial do Instituto de Pesquisas Jardim Botânico do Rio de Janeiro, posicionados por georreferenciamento.
- Satélite: Esri World Imagery.
